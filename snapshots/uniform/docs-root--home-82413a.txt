Three ways to use AI with Uniform
#
Editors use Scout in the dashboard. Developers use Agent Skills and the MCP server in their own tools. All three follow your AI guidance.
Scout
The AI agent in the Uniform dashboard. It builds and translates content, and sets up tests. It changes drafts only.
MCP server
Lets Claude Code, Cursor, GitHub Copilot and other MCP clients read and change your Uniform project.
Agent Skills
Open-source skills that teach coding assistants the correct Uniform patterns.
