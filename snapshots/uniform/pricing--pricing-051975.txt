Uniform pricing FAQ
What is Uniform Composable DXP?
Uniform Composable DXP
is a platform that enables businesses to build and manage digital experiences by integrating best-of-breed tools. It allows users to choose and compose the tools they need, such as
CMS
, analytics, and personalization tools, offering flexibility and the ability to deliver omnichannel experiences. Unlike monolithic systems or product suites, Uniform Composable DXP supports openness and interoperability, ensuring that tools from different vendors can work seamlessly together. This approach benefits marketers by providing no-code tools for creating and personalizing experiences while developers maintain control over the back-end infrastructure, ensuring efficiency and innovation. Key features include the orchestration of composable tools,
visual editing
, advanced API connections, omnichannel delivery, content automation,
personalization
, and
A/B testing
.
What are Projects (production vs preprod)?
In Uniform, a project is a collection of configurations that drive an experience. This includes settings for classification, personalization, and layout of a web application. Projects can be live production instances or pre-production projects used for development, staging, or other scenarios. After logging in, projects are accessed through a dashboard in the Uniform app and are associated with the selected team. New projects can be created or deleted via the Uniform CLI or dashboard.
What are Content Entries?
Content Entries are design-agnostic content structures (e.g., articles, products) used in digital compositions, with content linked to UI via components and APIs. Content Entries integrate seamlessly into compositions, utilizing auto-generated data types for querying, and are accessible via the Uniform Platform API, Uniform Edge Delivery API, and SDK for custom applications.
What are Content Types?
Content types in Uniform define the structure for individual pieces of content, such as blog posts or articles. They consist of fields that organize content elements, like a single-line text input for titles, multi-line input for summaries, date pickers for publish dates, and rich text editors for body content. Content types help standardize and manage content, ensuring reusability and consistency across projects. Users can create content types by defining a name, a unique public ID, optional settings (e.g., use for blocks, auto-generate data types), and adding fields that determine the type of content allowed within the type.
What are Compositions?
A composition in Uniform is a foundational element that defines the experience created for end users. It is managed using
Uniform Visual Workspace
, where digital teams use components to build experiences within constraints set by developers. This approach ensures flexibility, consistency in user experience, and control over application design and performance.
What are Assets?
Assets in Uniform are media elements that can be added to compositions or content entries. They come from three main sources: libraries, data resources, or custom URLs. Each asset has properties like URL, alt text, width, height, and size, and these can be configured or overridden within a composition without affecting the original asset.
Uniform provides a lightweight asset library to store assets, supports previewing them, and offers features such as reordering and removing assets in the composition's property panel. The assets parameter also enables adding or managing multiple assets in a seamless way, depending on how it is configured. API responses provide asset data as an array with fields.
What is Personalization?
Uniform provides a powerful
personalization platform
that enables tailored digital experiences using audience data, analytics integration, edge-CDN functionality, and control groups for measurable results.
What are Signals?
A signal is a feature used in
Uniform Personalization
and Analytics to assess and classify visitor behavior based on specific criteria. Signals are assigned scores to track and measure visitor interactions, which can then be used to personalize experiences or influence decision-making processes.
What is A/B testing?
A/B testing
is a method where two or more versions of a digital experience (variants) are shown to different groups of users to compare their performance. It exposes certain users to changes (e.g., design, content, or functionality) while others experience the original version. Based on user engagement data, you can determine which version performs better and decide whether to implement the changes or stick with the original. In the Uniform platform, A/B testing involves assigning visitors to variations using random number generation, setting visitor distribution percentages, and integrating with analytics tools to track and measure the effectiveness of each test. Results can be analyzed via Uniform's dashboard or connected tools like Google Analytics to declare a winning variant and apply it to all users.
What are Locales?
Uniform offers a robust system for
internationalization and localization
, enabling content adaptation across languages and regions while maintaining brand consistency through tools like locale grouping, translation management, and structural localization.
Locales are central to internationalization in Uniform and represent different language or regional settings. A locale is defined by its display name (like "English US"), a locale code (e.g., "en-us"), and a Boolean value indicating if it is the default project locale. Locale codes typically follow ISO standards, such as "en-GB" or "es-ES," ensuring seamless integration with other systems and browser preferences.
Locales enable translating and customizing parameters or fields for specific regions or languages by marking them as "localizable." They can also be grouped (e.g., "en-CA" and "fr-CA" for Canada) for easier management and bulk operations. The Uniform platform provides tools like APIs and locale-specific localization functions to facilitate managing locale-specific data efficiently.
Does Uniform DXP have AI?
Uniform provides advanced AI tools, including
agentic AI agents and composable generative AI solutions
, to enhance digital experiences,
optimize SEO/CRO
, and manage translations effectively. Uniform offers 24/7 support and integration with leading AI and translation services.
What are Integrations (pre-built vs custom)?
Uniform pre-built integrations
are pre-built connectors built and maintained by Uniform. Only integrations that bring content into your components count toward your integration limit. For example, visitor data and tracking integrations (analytics, CDP, etc.) don’t count toward integration limits. A custom integration with Uniform is either a generic HTTP integration that you install and configure to point to your API or a custom integration that you build with our Mesh SDK.
What is a Release?
The Uniform Release feature allows for previewing, editing, and scheduling updates to content with a structured process for managing changes, permissions, and limitations, ensuring seamless deployment to production environments.
What are Workflows?
Workflows in Uniform are tools that enable you to operationalize content creation and publishing processes by defining custom content pipelines. These workflows can be assigned to components or content types to streamline various tasks. Once applied, workflows provide clear guidance on the current stage of content and facilitate transitions between stages.
What are Editions?
Uniform Editions are independent versions of a composition or content entry in Uniform, designed to support complex global, regional, or campaign-specific content needs. Each edition has its own unique content, structure, locales, and publishing lifecycle, enabling flexibility for managing market-specific or seasonal content variations. Editions are attached to a composition or entry and are resolved dynamically based on the current locale or priority settings.
What is Single Sign On?
Single Sign-On (SSO) is an authentication method that allows users to log in to multiple applications or services using a single set of credentials, rather than managing separate credentials for each platform. In the context of Uniform, users can log in using their email, Google, or GitHub credentials. For organizations utilizing other SSO providers, such as Auth0 or Microsoft Entra ID (Azure Active Directory), Uniform offers integrations to enable seamless access across services.
What are Insights?
Uniform Insights is a real-time analytics tool for marketers. It offers instant insights into
A/B testing
,
personalization
performance, and digital property optimization. Uniform Insights has
seamless integrations
, strong data privacy controls, and no reliance on cookies or tracking pixels.
What Support does Uniform offer (Bronze, Silver, Gold, Platinum)?
Uniform offers 4 levels of Customer Support, and all plans include some level of Support. The Uniform Customer Support tiers offer 4 levels of support, including Bronze, Silver, Gold, and Platinum. The plans vary by SLA response times, communication channels, and availability.
