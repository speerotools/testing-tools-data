Integrating Sitecore with agentic platforms
Sitecore is designed to work across multiple ecosystems, supporting both established and emerging technologies. One emerging area is the use of
agentic platforms
. These platforms rely on one or more AI agents to act independently to carry out tasks and run workflows on behalf of users.
Connecting Sitecore with agentic and generative AI platforms enables more automated and connected digital experiences. The following section explains how this works through Sitecore interoperability.
Sitecore interoperability
Interoperability
means Sitecore can connect and work together with other systems without needing custom rebuilds.
Sitecore interoperability includes:
Partner integrations
- solutions from partners such as Altudo, Horizontal Digital, Icreon, EPAM, and Deloitte that extend Sitecore into wider ecosystems.
APIs and developer tools
- APIs and integration guidance for consistent connectivity.
Future-ready approach
- frameworks designed to support new and emerging technologies, including agentic and generative AI platforms.
Gradial integration
Gradial
is the first partner to provide an integration based on this interoperability approach. The integration connects the Gradial agentic platform with Sitecore APIs and enables Gradial agents to perform tasks in Sitecore products:
SitecoreAI
- create and update pages, manage content items, and apply bulk changes through the Sitecore GraphQL and REST APIs.
Content Hub
- generate and manage assets, synchronize content, and orchestrate campaigns within content workflows.
For instructions on how to integrate Sitecore and Gradial, see the
Gradial documentation
.
Agent API
To extend the interoperability beyond partner integrations, Sitecore introduced a dedicated
Agent API
. This REST API supports:
Automating workflows across Sitecore and agentic platforms.
Delivering contextual, real-time content.
Orchestrating more complex digital experience scenarios.
Enabling AI agents to perform actions in Sitecore through the
Marketer MCP
. For more information, see
Marketer MCP and Agent API overview
.
