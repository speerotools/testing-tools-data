ablyft.get()
Read project data and runtime state from the snippet.
ablyft.get(type, argument?)
returns data depending on
type
. An unknown type logs
ABlyft - Unknown API type
to the console and returns
undefined
.
type
Returns
data
Basic project and snippet information
activePageIds
IDs of the currently active pages
activeExperimentIds
Currently active experiments
pingedGoals
Goals recorded while testing in preview or QA mode
pages
/
experiments
/
goals
Raw project data lists
variationById
/
goalById
A single variation or goal
trackingConsentEnabled
Stored consent state
deviceType
Device type of the visitor
bucketing
Variation assignment of the visitor
preview_bucketing
Variations selected via preview mode
tools
The tools object
data
Copy Anchor Link
Object with the following values:
Property
Meaning
projectId
The project the snippet belongs to.
version
The snippet version.
revision
The publication number. It increases with every
publication
. Compare it with
Snippet revision
in the snippet settings to see whether you get the latest version.
goalsEnabled
false
means goals are not counted, which is the case in preview mode.
isPreview
true
if preview mode is active.
optedOut
true
if you opted out in this browser.
storage
Where the snippet stores data (
default
or a custom setting).
