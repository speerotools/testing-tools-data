Overview of the experimental Confidence MCP servers: what each server does, its endpoint and authentication, and how to connect your AI assistant.

Model Context Protocol (MCP) servers expose Confidence operations as tools that an AI assistant can call. This page lists the public Confidence MCP servers and shows how to connect them. For a guided setup, see
Set Up Confidence for Your AI Assistant
.
The Confidence MCP servers are experimental. Tools and their parameters can change.

MCP Servers and the Confidence Agent
The MCP servers and the in-app Confidence Agent are separate tools:
The
MCP servers
run inside your own AI assistant, such as Claude Code, Codex, Cursor, or VS Code. To create a metric with an assistant, use the Flags MCP server. The Confidence Agent doesn’t create metrics.
The
Confidence Agent
runs inside the Confidence app. It covers jobs that MCP doesn’t, such as creating and launching experiments. See
Work with the Confidence Agent
.

no authentication

requires authentication
