Snowflake
Use Snowflake as a destination
Copy page
Copy page
Send Kameleoon experiment exposure events to Snowflake to centralize campaign results and analyze them alongside your existing data.
Copy page
Copy page
Data warehouse integrations are available as a premium add-on for the Web Experimentation and Feature Experimentation module. Contact your Customer Success Manager for more information.
Kameleoon can write campaign events into a Snowflake database that you own, where you query them with SQL. The integration writes experiment exposure events by default, and it can also write conversion and custom data events, each to its own table in the
KAMELEOON_EVENTS
schema that you create in
Setting up Snowflake
. Use key-pair authentication for this direction, because the destination doesn’t support password authentication.
​
Activate Snowflake as a destination
Once you have
enabled the Snowflake integration for your project
, you can activate
Use Snowflake as a destination
to start writing Kameleoon events to Snowflake.
To do so, follow these steps:
In the selected project’s configuration, click
Use Snowflake as a destination
to expand it.
Enter the name of the warehouse that you granted to the Kameleoon role in
Setting up Snowflake
in the
Warehouse
field, then click
Confirm
.
Click
Validate
to save and apply your configuration settings.
​
What “Use Snowflake as a destination” does
Enabling
Use Snowflake as a destination
starts writing Kameleoon events to Snowflake.
Kameleoon saves the events in the
KAMELEOON_EVENTS

KAMELEOON

Kameleoon enables experiment exposure events by default. Conversion and custom data event collection is new and may change. You can’t turn it on in the UI. To activate it, contact the Kameleoon support team.
​
Limits of the destination
Kameleoon only inserts rows into these tables. It doesn’t read changes back from Snowflake, so a correction or deletion in your tables doesn’t change the events that Kameleoon has already written.
Kameleoon doesn’t monitor the schema of these tables. If you change a column, Kameleoon doesn’t detect the change.
