Overview of PBX Ideate plans, usage tracking, and the upgrade process.
Copy page
Copy page
PBX Ideate offers a freemium model. All Web Experimentation customers and PBX Build users automatically have access to the
Basic (Free)
tier. You can upgrade to the
Premium
plan as a paid add-on to unlock unlimited use.
​
Basic (Free) plan
Each analysis is scoped to one page and one version. Analyzing both the Desktop and Mobile version of the same URL counts as 2 analyses, not 1.
The Basic plan provides
5 successful analyses per year
. Kameleoon shares this quota across all projects and users in your workspace. You can distribute these analyses across any number of pages (for example, 2 analyses on one page and 3 on another, or 5 analyses on a single page).
Credit consumption:
Kameleoon only deducts a credit when an analysis completes successfully (
DONE
status).
Retry:
if an analysis fails (
ERROR
status), it doesn’t consume a credit. You can retry it for free.
Analyze again:
re-running the analysis on a page that already completed successfully consumes 1 analysis, the same as a new page. Analyze again is only available starting 30 days after the page’s last successful analysis.
Deletions:
Deleting a page does not refund the credit used to analyze it.
​
Premium plan
The Premium plan provides
unlimited analyses
with no annual quota or project limits.
​
Track plan usage
Kameleoon shows your current usage as a progress bar in the
Plan usage
widget, inside the
Analyze pages
modal, before you start an analysis.
Progress bar:
a stepped bar with 5 segments tracks your annual usage. The bar changes color as you approach the limit, and turns red when you reach 5/5.
Dynamic notifications:
warning messages appear as you approach or hit your limit.
Service lockout:
when you reach 5/5 analyses, Kameleoon disables the
Add page
button. You must upgrade to Premium to continue analyzing pages.
​
Analyze again disabled
Kameleoon greys out
Analyze again
on a page card with an info tooltip when the action isn’t available yet:
Still in the 30-day cooldown:
the tooltip reads “To keep results relevant, each page can be analyzed once every 30 days.”
Basic plan’s annual quota exhausted:
the tooltip reads “You’ve reached your annual analysis limit: you won’t be able to analyze this page until your quota resets or you upgrade to Premium,” with an
Upgrade to Premium
link.
​
Upgrade to Premium
You can start an upgrade request from the
Plan usage
widget or from the
Upgrade to Premium
link in a disabled
Analyze again
tooltip.
Click
Upgrade to Premium
.
Review the plan comparison modal.
Click
Send upgrade request
.
After you submit the request, a Customer Success Manager (CSM) contacts you to complete the process. You don’t need to submit payment immediately.
