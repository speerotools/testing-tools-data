Safari support added to Adobe Target
. Target is now supported in the Safari browser. Note that Visual Experience Composer and Enhanced Experience Composer are not supported in Safari. As a result, an overlay now appears in the VEC to notify users that they must switch to Chrome to use the editor. (TGT-55853)
