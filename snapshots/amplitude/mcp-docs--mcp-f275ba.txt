Frequently asked questions
What does MCP stand for?
MCP stands for Model Context Protocol. It’s an open-source standard for connecting AI applications to external systems, kind of like a USB-C plug for all your AI tools. You can read more about it
here
.
Is access to Amplitude MCP free?
Amplitude MCP is available to all Amplitude customers, so even if you're on the
Free plan
, you can connect to it. You will separately need to have access to the AI application you want to connect with, and that may involve creating a paid account.
Does Amplitude MCP connect to other AI applications not listed on this page?
The links above are just the applications that we have native connectors built with today. You can also build your own connector to any AI tool you want as long as it supports MCP servers.
Learn how with our documentation
!
How does Amplitude MCP work?
First connect and authenticate your preferred AI tool to Amplitude’s MCP server. Your AI tool can then query data from your Amplitude account when responding to prompts. Our server acts as an interface for connecting Amplitude’s structured context to LLM-based AI systems like Claude, Cursor, and Gemini. It provides a comprehensive set of tools that enable LLMs to:
Search or create dashboards, charts, notebooks, cohorts, and experiments
Query and analyze user data, such as acquisition, conversion, retention engagement, and user feedback
Retrieve feature flags and experiment results
Access project context, events, and user properties
We’ll continue adding new capabilities in the near future based on learnings and customer feedback.
How is customer and end-user data handled by Amplitude’s MCP server?
The MCP server uses your existing Amplitude user permissions and access controls. OAuth authentication ensures a secure connection between the MCP server and your Amplitude account. You can only access Amplitude projects and data that you already have permission to view in your regular Amplitude account. You receive no additional data access beyond your current Amplitude account privileges.
