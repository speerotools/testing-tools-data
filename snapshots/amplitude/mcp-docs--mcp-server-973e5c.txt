Frequently asked questions
What does MCP stand for?
MCP stands for Model Context Protocol. It’s an open standard that lets AI applications retrieve context and call tools from external systems. Learn more about it
here
.
Is access to Amplitude MCP free?
Amplitude MCP is available to every Amplitude customer on every plan, including the free Starter plan. The AI application you connect it to may require a separate account or subscription.
Which AI tools work with Amplitude MCP?
The featured connectors are the AI tools and coding environments Amplitude customers use most: Claude and Claude Code, Cursor, ChatGPT, Codex, and Lovable. You can also connect through Figma, GitHub, Kiro, Notion, Rovo, and other AI applications that support remote MCP servers. Outreach support is coming soon.
See current setup instructions
.
How does Amplitude MCP work?
Connect and authenticate a compatible AI application to Amplitude through OAuth. The client can then use Amplitude MCP to:
Search and create charts, dashboards, notebooks, cohorts, and experiments.
Analyze acquisition, conversion, retention, engagement, user behavior, feedback, and session replays.
Retrieve feature flags and experiment results.
Access project context, events, and properties.
You ask in natural language; the client selects the appropriate Amplitude tools using your existing permissions. Amplitude MCP can manage event and property definitions in your tracking plan, but it does not send production event data. Use an Amplitude SDK or the HTTP V2 API to instrument your product.
How is customer and end-user data handled by Amplitude’s MCP?
Amplitude MCP uses OAuth and your existing Amplitude permissions and access controls. The connected AI application can access only the projects and data the authenticated user can already view in Amplitude. It does not grant additional access or create a separate permissions model.
