Check your integration
If you open your application now, it should start sending events.
To check if your integration is working, go to the
Integration page
of your application.
When working correctly, you should see a green bullet next to the
Status

“Received traffic in the past 24 hours”
. If you still do not see this message after a few minutes, see the
Troubleshooting
reference.
