Get to Know Monetate
Monetate uses real-time behavior, contextual data, and more to personalize customer experiences.
JavaScript API
The JavaScript API passes page-level data to drive targeted, personalized, browser-based site changes.
Engine API
The Engine API provides direct entry to Monetate's decision engine for omnichannel personalization.
SDKs
The SDKs simplify Engine API calls to quickly serve personalization experiences for any channel.
Personalized Search API
The Personalized Search API works with the Engine API to personalize site searches.
Auth API
Use the Auth API to manage JSON Web Tokens (JWT) for authentication with Monetate.
Data API
Use the Data API to create and send data across any channel to Monetate's decision engine.
Metadata API
Use the Metadata API to retrieve interpretable values for experiences, page events, and targets.
Data Privacy APIs
Use the Data Privacy APIs to comply with customer data privacy requests and regulations.
