Introduction
Copy Page
This section details Split API. Split API uses resource-oriented URLs, uses status codes to indicate the success or failure of requests and returns JSON from all requests.
You can use Split API to push data into Split, get data out of Split, build custom integrations, or build on top of the Split platform.

Getting Started?
If you're just getting started with Split, we encourage your to visit our
Developer Hub
site. You'll learn how to set up our SDKs and release a feature without re-deploying your application.
